# 剪切板工具（Windows exe）可行性分析与设计报告

- 技术方案：Tauri 2 + Vue 3 + TypeScript + SQLite
- 目标平台：Windows 10 / 11（x64），交付形式为 exe（安装包 + 可选便携版）
- 文档用途：项目立项说明，可直接作为 Cursor 的项目上下文（见第 11 节）

> 说明：文中涉及的插件与系统接口为我对 Tauri 2 生态的了解，开工前请对照官方文档确认当前版本的 API 与插件名称。

---

## 第一部分：可行性分析

### 1. 结论

**可行，风险低到中等，建议立项。** 核心能力（监听剪切板、全局快捷键、托盘、开机自启、本地数据库、打包 exe）在 Tauri 2 里都有官方或成熟社区插件。主要风险集中在两处：自动粘贴到前一个窗口（需要调用 Windows 系统接口），以及剪切板监听插件的稳定性。这两项都有退路，见风险表。

### 2. 技术可行性逐项评估

| 能力 | 实现方式 | 可行性 | 备注 |
|---|---|---|---|
| 读写剪切板（文本） | 官方 clipboard-manager 插件 | 高 | 官方插件只负责读写，不负责监听变化 |
| 监听剪切板变化 | 社区剪切板插件，或在 Rust 侧直接用 Windows 的剪切板格式监听接口（`AddClipboardFormatListener`） | 中高 | 必须用系统事件，不要轮询；插件不稳定时可自己写约 100 行 Rust |
| 读取图片 | Rust 侧读取位图，转 PNG 后存本地文件 | 中高 | 放在 V1.1，图片只存文件，数据库只存路径与缩略图 |
| 全局快捷键 | 官方 global-shortcut 插件 | 高 | 需处理快捷键被其他软件占用的情况，并允许用户修改 |
| 托盘常驻 | Tauri 内置托盘能力 | 高 | |
| 开机自启 | 官方 autostart 插件 | 高 | 写注册表启动项 |
| 本地存储 | SQLite（官方 sql 插件，或 Rust 侧使用 rusqlite） | 高 | 全文搜索可先用 `LIKE`，数据量大再换 FTS5 |
| 单实例运行 | 官方 single-instance 插件 | 高 | 防止多开重复监听 |
| 窗口记忆位置 | 官方 window-state 插件 | 高 | |
| 回车自动粘贴到原窗口 | 先把内容写回剪切板，隐藏自身窗口，再用 Windows 的按键模拟接口发送 Ctrl+V | 中 | 本项目最大的技术点，见风险 R1 |
| 无边框、置顶、不抢焦点的弹窗 | Tauri 窗口配置（无边框、置顶、跳过任务栏） | 中高 | “不抢焦点”需要额外处理，见风险 R1 |
| 打包为 exe | Tauri 打包器，生成 NSIS 安装包；直接取 release 目录下的 exe 也可作便携版 | 高 | 便携版要求用户系统有 WebView2 运行时（Win11 自带，Win10 多数已有） |

### 3. 开发者能力匹配度

- 前端界面部分用 Vue 3，与你现有技能完全匹配，占整体工作量约 60%。
- Rust 部分只需做“薄薄一层”：剪切板监听、粘贴模拟、SQLite 读写，约占 40%。这部分可以借助 Cursor 生成并解释，学习成本可控。
- 建议你把 Rust 代码限制在 `src-tauri/src/` 下几个小模块里，Vue 通过 `invoke` 调用，边界清晰。

### 4. 环境与成本

- 开发环境：Node.js、Rust 工具链、Visual Studio C++ 生成工具（MSVC）、WebView2。仅 Windows 本机即可，不需要服务器。
- 费用：开发阶段为 0。发布阶段可选代码签名证书（约每年数百到上千元），不签名也能用，但会被 SmartScreen 提示，部分杀毒软件可能误报。
- 体积预期：安装包几 MB 到十几 MB；常驻内存预期在几十 MB 量级（取决于 WebView2，窗口隐藏时可进一步降低）。以上为经验预估，需要做原型实测。

### 5. 风险与对策

| 编号 | 风险 | 影响 | 对策 |
|---|---|---|---|
| R1 | 自动粘贴失败：弹窗抢走焦点后，Ctrl+V 发到了错误的窗口 | 核心体验受损 | 呼出前记录前台窗口句柄；粘贴时先隐藏自身、恢复原窗口焦点，再发送按键；兜底方案为仅写回剪切板，由用户手动 Ctrl+V |
| R2 | 剪切板监听插件不稳定或漏事件 | 历史记录缺失 | 优先自己用系统事件监听；加入内容哈希去重与异常日志 |
| R3 | 收录了密码等敏感内容 | 隐私与信任风险 | 识别 Windows 剪切板中“不要收录”的标记格式并跳过；支持应用黑名单；一键清空；数据可选加密 |
| R4 | 杀毒软件误报（监听剪切板 + 模拟按键的行为类似木马） | 用户无法安装 | 代码签名；开源；发布说明中解释权限用途 |
| R5 | 全局快捷键冲突 | 无法呼出 | 设置页可改键；注册失败时给出提示 |
| R6 | 图片/大文本占用磁盘与内存 | 变慢、占空间 | 图片落盘不入库；单条大小上限；历史条数与保留天数可配置 |
| R7 | WebView2 缺失（便携版） | 打不开 | 安装包内置引导安装 WebView2；便携版文档中说明 |
| R8 | 管理员权限窗口收不到自动粘贴 | 个别场景失效 | 文档说明；必要时提供“以管理员身份运行”选项 |

### 6. 原型验证清单（建议先花 1 到 2 天完成）

按风险从高到低验证，全部通过再正式开发：

1. 监听文本剪切板变化，并在 Vue 界面实时显示。
2. Alt+V 呼出无边框窗口，且按 Esc 或点击外部可关闭。
3. 在记事本、浏览器、VS Code 中选中一条记录按回车，能自动粘贴到原来的输入位置。
4. 复制来自密码管理器的内容时，能识别并跳过。
5. 打包出 exe，在一台干净的 Windows 虚拟机里安装并运行。

## 第二部分：设计报告

### 7. 产品概述

**一句话定位**：一个轻量、本地优先、键盘驱动的 Windows 剪切板历史工具。

**目标用户**：经常需要在多个窗口间复制粘贴文本的开发者和办公用户。

**核心价值**：
1. 快：快捷键呼出，输入即搜索，回车即粘贴。
2. 轻：安装包小，常驻内存低。
3. 私：所有数据只存在本机，不联网。

**非目标（第一版不做）**：云同步、移动端、团队共享、OCR、AI 功能。

### 8. 功能需求

**MVP（P0）**
- 自动记录文本复制历史，连续相同内容去重。
- 全局快捷键（默认 Alt+V）呼出，位置靠近鼠标或屏幕居中。
- 搜索框自动聚焦，输入即过滤。
- 上下键选择，回车粘贴到原窗口，Esc 关闭。
- 收藏/置顶，收藏项不会被自动清理。
- 删除单条、清空全部。
- 托盘常驻，右键菜单：打开、暂停记录、设置、退出。
- 开机自启（可开关）。
- 设置：快捷键、最大历史条数、保留天数、开机自启。

**V1.1（P1）**
- 图片与文件路径支持。
- 按类型过滤（文本/链接/图片/代码）。
- 应用黑名单与敏感内容跳过。
- 以纯文本方式粘贴（Shift+回车）。
- 深色/浅色主题。

**V2（P2）**
- 代码高亮与 JSON/文本格式化。
- 标签与分组、片段模板。
- 数据加密、导入导出。

### 9. 系统设计

#### 9.1 架构

```
┌────────────────────────── Tauri 应用 ──────────────────────────┐
│  前端（WebView2）                  后端（Rust）                  │
│  Vue 3 + TS + Pinia                                              │
│  ┌──────────────┐   invoke    ┌──────────────────────────────┐  │
│  │ 历史列表/搜索 │ ──────────▶ │ commands（对前端暴露的命令）  │  │
│  │ 设置页       │ ◀────────── │                              │  │
│  └──────────────┘   event     │ clipboard_watcher 监听剪切板  │  │
│                               │ paste_service   自动粘贴      │  │
│                               │ storage         SQLite 读写   │  │
│                               │ shortcut / tray / autostart   │  │
│                               └──────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                         本地：SQLite 文件 + 图片目录
```

要点：
- 前端只负责展示与交互，所有系统能力与数据读写都在 Rust 侧。
- 剪切板有新内容时，Rust 先入库，再通过事件通知前端刷新。
- 主窗口平时隐藏，不销毁；呼出时只显示并聚焦，保证响应快。

#### 9.2 目录结构

```
clipboard-tool/
├─ src/                      前端（Vue）
│  ├─ views/                 HistoryView.vue, SettingsView.vue
│  ├─ components/            ClipItem.vue, SearchBar.vue
│  ├─ stores/                clips.ts, settings.ts（Pinia）
│  ├─ api/                   对 invoke 的类型化封装
│  └─ main.ts
├─ src-tauri/
│  ├─ src/
│  │  ├─ main.rs / lib.rs    应用入口与插件注册
│  │  ├─ commands.rs         暴露给前端的命令
│  │  ├─ watcher.rs          剪切板监听
│  │  ├─ paste.rs            记录前台窗口、恢复焦点、模拟粘贴
│  │  ├─ storage.rs          SQLite 访问
│  │  └─ settings.rs         配置读写
│  ├─ capabilities/          权限声明
│  └─ tauri.conf.json
└─ docs/                     本文档
```

#### 9.3 数据模型（SQLite）

`clips` 表：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER 主键 | 自增 |
| kind | TEXT | text / image / file |
| content | TEXT | 文本内容；图片则为空 |
| file_path | TEXT | 图片或文件的本地路径 |
| hash | TEXT 唯一索引 | 内容哈希，用于去重 |
| source_app | TEXT | 来源应用名（用于黑名单） |
| pinned | INTEGER | 是否收藏 |
| use_count | INTEGER | 使用次数 |
| created_at | INTEGER | 首次时间戳 |
| updated_at | INTEGER | 最近一次复制或使用时间 |

`settings` 表：键值对，存快捷键、保留策略等配置。

去重规则：哈希已存在则只更新 `updated_at`，并把它排到最前。

#### 9.4 前后端接口（命令与事件）

| 名称 | 类型 | 说明 |
|---|---|---|
| `list_clips(query, kind, limit, offset)` | 命令 | 分页与搜索 |
| `paste_clip(id, plain)` | 命令 | 写回剪切板、隐藏窗口、恢复焦点并粘贴 |
| `toggle_pin(id)` | 命令 | 收藏切换 |
| `delete_clip(id)` / `clear_clips(keepPinned)` | 命令 | 删除 |
| `get_settings()` / `update_settings(patch)` | 命令 | 设置 |
| `set_recording(enabled)` | 命令 | 暂停或恢复记录 |
| `clip-added` | 事件 | 有新记录时通知前端刷新 |
| `window-shown` | 事件 | 窗口被呼出，前端聚焦搜索框并重置选中项 |

#### 9.5 关键流程

**记录流程**：系统通知剪切板变化 → 读取内容 → 判断是否带有“不收录”标记或来自黑名单应用 → 计算哈希 → 去重入库 → 触发保留策略清理 → 发出 `clip-added`。

**呼出并粘贴流程**：
1. 按下全局快捷键，Rust 记录当前前台窗口。
2. 显示主窗口并聚焦，前端清空搜索框。
3. 用户搜索、选择，按回车。
4. Rust 把所选内容写回剪切板（此动作要标记为“自己写入”，避免被监听器当成新记录）。
5. 隐藏主窗口，恢复原前台窗口焦点。
6. 等待极短时间后发送 Ctrl+V。
7. 失败则保留在剪切板中，并提示“已复制，请手动粘贴”。

#### 9.6 界面设计

- 主窗口：约 420×520 的无边框圆角窗口，置顶，不显示在任务栏。顶部搜索框，下方为列表；每行显示内容前两行、类型图标、相对时间、收藏星标。底部显示快捷键提示。
- 选中项右侧或下方可展开完整预览。
- 设置页：快捷键、保留策略、开机自启、黑名单、主题。
- 键盘优先：↑↓ 选择，回车粘贴，Shift+回车纯文本粘贴，Ctrl+P 收藏，Delete 删除，Esc 关闭。

#### 9.7 非功能性要求

- 性能：呼出到可输入小于 150ms（目标值，需实测）；1 万条记录下搜索无明显卡顿。
- 资源：窗口隐藏时常驻内存尽量低；剪切板监听基于系统事件，空闲时不占 CPU。
- 隐私与安全：默认不联网；数据库存本地用户目录；提供一键清空；V2 提供加密选项。
- 稳定性：单实例；崩溃后重启不丢历史；关键错误写入本地日志。

## 第三部分：给 Cursor 的使用说明

### 11. 如何提交给 Cursor

1. 新建项目目录，把本文件放到 `docs/design.md`。
2. 在项目根目录新建 `.cursor/rules/project.mdc`，写入项目约定（可直接用下面这段）。
3. 先让 Cursor 完成 M0 原型，逐项验证通过后再进入后续阶段。

**项目约定（可放入 rules）**

```
这是一个 Windows 剪切板工具，技术栈为 Tauri 2 + Vue 3 + TypeScript + SQLite。

约定：
- 前端只做展示与交互，系统能力与数据读写放在 src-tauri 的 Rust 模块里，通过 invoke 与事件通信。

- Rust 代码按 watcher / paste / storage / settings 拆模块，每个模块保持小而清晰。
- 默认不联网，不引入遥测。
- 每完成一个里程碑，先给出手动验证步骤再继续。

```
